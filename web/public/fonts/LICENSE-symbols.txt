instrument-symbols.woff2
========================

A seventeen-glyph cut, shipped so that the icons this interface draws as text cannot be
replaced by whichever font an operating system happens to offer.

  source   DejaVu Sans Mono, Version 2.37 — https://dejavu-fonts.github.io/
  glyphs   U+03A3 Σ   U+2190 ←   U+2192 →   U+21B5 ↵   U+21BB ↻   U+2315 ⌕
           U+2502 │   U+2514 └   U+25B2 ▲   U+25B8 ▸   U+25BC ▼   U+25BE ▾
           U+25C6 ◆   U+25CC ◌   U+270E ✎   U+2713 ✓   U+2715 ✕
  changes  Subset to the code points above. Every advance width set to 1229/2048 em
           (0.6001 em, the mono cell of JetBrains Mono) so the glyphs sit on the same
           grid as the surrounding text. Internal name records rewritten to "Instrument
           Symbols" per the renaming clause below; the copyright record is untouched.
           No outline was altered.
  rebuild  pyftsubset DejaVuSansMono.ttf --unicodes=<the code points above> \
             --flavor=woff2 --no-glyph-names --layout-features= \
             --output-file=instrument-symbols.woff2
           then, with fontTools, put the glyphs on that grid and rename the cut:

             f = TTFont("instrument-symbols.woff2")
             for name in f.getBestCmap().values():
                 f["hmtx"][name] = (1229, f["hmtx"][name][1])
             f["hhea"].advanceWidthMax = 1229
             for nid, val in {
                 1: "Instrument Symbols", 2: "Regular",
                 3: "InstrumentSymbols-Regular; subset of DejaVu Sans Mono 2.37",
                 4: "Instrument Symbols Regular", 6: "InstrumentSymbols-Regular",
                 13: "Bitstream Vera licence; see web/public/fonts/LICENSE-symbols.txt",
             }.items():
                 f["name"].setName(val, nid, 3, 1, 0x409)
                 f["name"].setName(val, nid, 1, 0, 0)
             f.save("instrument-symbols.woff2")

Only these seventeen code points are declared in the @font-face unicode-range, so
JetBrains Mono and Inter Grot keep every glyph they do have. See web/src/index.css.
